# SnapFit

AI-powered photography assistant for Android and iOS.

## Project Structure

```text
snapfit-app/
├── mobile/      # Mobile application
├── backend/     # Backend API
├── README.md
└── .gitignore
```

## Tech Stack

* Mobile: React Native
* Backend: Node.js + TypeScript
* Database: PostgreSQL
* AI / Computer Vision: Python

## Project Goal

SnapFit helps users take photos based on reference images by providing AI-powered guidance for pose, composition, camera angle, and distance.
